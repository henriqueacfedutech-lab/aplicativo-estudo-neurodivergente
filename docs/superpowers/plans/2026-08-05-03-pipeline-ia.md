# Pipeline de IA — Geração e Revisão (Plano 3/5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implementar `gerarFichaIA` e `gerarProblemaIndependente` (spec, Seção 5) com o passo de autorrevisão (spec, Seção 6): fidelidade à fonte, conformidade com o guia de Carga Cognitiva, correção factual — com 1 regeneração automática em caso de falha e log persistente em `review_log`.

**Architecture:** Duas funções de orquestração (`gerarFichaIA`, `gerarProblemaIndependente`), cada uma: busca os trechos-fonte com ID rastreável via `pgvector`, chama a IA para gerar conteúdo estruturado, chama a IA de novo para revisar esse conteúdo contra a própria fonte, regenera 1x se a revisão falhar, persiste o resultado final em `fichas`/`problems`, e grava o resultado da revisão em `review_log` — sempre, passando ou não.

**Tech Stack:** `fetch` direto à API Anthropic (`claude-sonnet-5`, mesmo padrão das 6 chamadas existentes no app), `@supabase/supabase-js@2` (Plano 1), `match_knowledge_chunks` (Plano 2).

## Global Constraints

(herdadas dos Planos 1 e 2, mais:)

- Este plano depende dos Planos 1 e 2 já implementados.
- **Este pipeline não tem fallback local** — ao contrário de `recuperarTrechosSemanticos` (Plano 2, que cai para busca por palavra-chave se o Supabase não estiver disponível), `gerarFichaIA`/`gerarProblemaIndependente` **exigem** Supabase + Voyage AI configurados, porque precisam do `id` de cada chunk para rastreabilidade (`source_chunk_ids`, usado pela revisão anti-alucinação) — um chunk vindo da busca local por palavra-chave não tem esse `id`. Isso é intencional e bate com a Seção 9 do spec ("Supabase offline → aviso restrito à área de fichas/diagramas").
- Todo problema/ficha gerado é sempre gravado em `review_log`, passando ou falhando na revisão (spec, Seção 6) — nunca pular esse registro.
- Segue a convenção existente de cache-consciência do app: antes de gastar uma chamada de IA, verifica se já existe (`gerarFichaIA` não regenera uma ficha já salva a menos que `forcarNova=true`, mesmo padrão de `gerarTrilhaPDF`/`gerarEsquemaIA`).

- [ ] **Step 1: Adicionar `recuperarChunksComId`**

```js
/* ═══ PIPELINE DE IA: FICHAS E PROBLEMAS ═══
   Diferente de recuperarTrechosSemanticos (que tem fallback local sem ID),
   este pipeline PRECISA do id de cada chunk para rastreabilidade — por isso
   chama match_knowledge_chunks direto e nunca cai para busca por palavra-chave. */
async function recuperarChunksComId(discId, consulta, n){
  if(!supabaseClient || !S.voyageApiKey) throw new Error('Configure Supabase e a chave Voyage AI em Ajustes antes de gerar fichas.');
  const [embedding] = await gerarEmbeddings([consulta], 'query');
  const { data, error } = await supabaseClient.rpc('match_knowledge_chunks', {
    query_embedding: embedding, p_disciplina_id: discId, match_count: n||5
  });
  if(error) throw error;
  if(!data || !data.length) throw new Error('Sem material-fonte indexado para este tópico. Envie um PDF desta disciplina antes de gerar.');
  return data.map(r=>({id:r.id, texto:r.texto}));
}
```

```js
async function gerarFichaIAConteudo(disciplinaId, topico, fonte){
  const d = DISC.find(x=>x.id===disciplinaId);
  CACHE.meta.chamadas = (CACHE.meta.chamadas||0)+1; salvarCache();
  const r = await fetch("https://api.anthropic.com/v1/messages", {
    method:"POST", headers: headersIA(),
    body: JSON.stringify({model:"claude-sonnet-5", max_tokens:1500, messages:[{role:"user", content:
`Leia o material abaixo sobre o tópico "${topico}" da disciplina ${d.nome} (concurso fiscal) e monte uma ficha de estudo seguindo a Teoria da Carga Cognitiva:
- conceito_central: no máximo 150 palavras, frases de no máximo 40 palavras.
- por_que_cai: 1 a 2 pontos curtos de relevância pra prova.
- diagrama_schema: esquema estruturado com "layout" (escolha entre sequencia, hierarquia, comparacao, ciclo, mapa — o que melhor representar o conteúdo), "titulo", "nos" (cada um com "id", "texto" curto, "enfase": "core" para regra/conceito-chave, "alert" para atenção/exceção/pegadinha, "anchor" para termo técnico, "neutro" caso não se aplique) e "relacoes" (cada uma com "de", "para" e "rotulo" opcional).
- problema_resolvido: um problema extraído ou adaptado diretamente do material, com "enunciado" e "explicacao" passo a passo.
Nunca invente conteúdo que não esteja no material abaixo.
Responda APENAS com JSON válido, neste formato exato:
{"conceito_central":"...","por_que_cai":"...","diagrama_schema":{"layout":"...","titulo":"...","nos":[{"id":"n1","texto":"...","enfase":"core"}],"relacoes":[{"de":"n1","para":"n2","rotulo":""}]},"problema_resolvido":{"enunciado":"...","explicacao":"..."}}

MATERIAL:
${fonte.slice(0,6000)}`}]})
  });
  const data = await r.json();
  const txt = data.content.map(c=>c.text||'').join('').replace(/```json|```/g,'').trim();
  const obj = JSON.parse(txt.slice(txt.indexOf('{'), txt.lastIndexOf('}')+1));
  if(!obj.conceito_central || !obj.diagrama_schema || !obj.problema_resolvido) throw new Error('Resposta da IA incompleta.');
  return obj;
}
```

```js
1. Fidelidade à fonte: todo fato/número/regra citado existe no material? Não pode haver invenção.

${JSON.stringify(conteudoGerado)}

MATERIAL-FONTE:
${fonte.slice(0,6000)}

Responda APENAS com JSON: {"passou": true ou false, "motivo": "explicação curta se passou=false, ou null"}`}]})
  });

  const txt = data.content.map(c=>c.text||'').join('').replace(/```json|```/g,'').trim();
```

### Task 2: `gerarFichaIA` — orquestração com cache, retry e persistência

**Files:**
- Modify: `Programa/tutor-fiscal.html` (mesma seção da Task 1)

**Interfaces:**
- Consumes: `recuperarChunksComId`, `gerarFichaIAConteudo`, `revisarConteudoIA`, `gravarReviewLog` (Task 1)
- Produces: `async function gerarFichaIA(disciplinaId, topico, forcarNova)` → `Promise<linha de public.fichas>` (com `__avisoRevisao: boolean` anexado). **Esta é a função que o Plano 5 (UI do card) chama na Tela 1.**

- [ ] **Step 1: Adicionar `gerarFichaIA`**

```js
async function gerarFichaIA(disciplinaId, topico, forcarNova){
  if(!supabaseClient) throw new Error('Configure a conexão com o Supabase em Ajustes antes de gerar fichas.');
  if(!forcarNova){
    const { data: existente, error: errBusca } = await supabaseClient
      .from('fichas').select('*')
      .eq('disciplina_id', disciplinaId).eq('topico', topico)
      .maybeSingle();
    if(errBusca) throw errBusca;
    if(existente){
      CACHE.meta.reusos = (CACHE.meta.reusos||0)+1; salvarCache();
      existente.__avisoRevisao = false;
      return existente;
    }
  }

  const chunks = await recuperarChunksComId(disciplinaId, topico, 5);
  const fonte = chunks.map((c,i)=>`[${i+1}] ${c.texto.slice(0,1200)}`).join('\n');

  let conteudo = await gerarFichaIAConteudo(disciplinaId, topico, fonte);
  let revisao = await revisarConteudoIA('ficha', conteudo, fonte);
  let tentouRegenerar = false;
  if(!revisao.passou){
    tentouRegenerar = true;
    conteudo = await gerarFichaIAConteudo(disciplinaId, topico, fonte);
    revisao = await revisarConteudoIA('ficha', conteudo, fonte);
  }

  const { data: linha, error: errSalvar } = await supabaseClient.from('fichas').upsert({
    disciplina_id: disciplinaId, topico,
    conceito_central: conteudo.conceito_central,
    por_que_cai: conteudo.por_que_cai,
    diagrama_schema: conteudo.diagrama_schema,
    problema_resolvido: conteudo.problema_resolvido,
    source_chunk_ids: chunks.map(c=>c.id)
  }, { onConflict: 'user_id,disciplina_id,topico' }).select().single();
  if(errSalvar) throw errSalvar;

  await gravarReviewLog({
    ficha_id: linha.id, tipo_conteudo:'ficha',
    passou: revisao.passou, motivo_falha: revisao.motivo, tentativa_regeneracao: tentouRegenerar
  });
  linha.__avisoRevisao = !revisao.passou;
  return linha;
}
```

```js
async function gerarProblemaIndependente(disciplinaId, topico){
  if(!supabaseClient) throw new Error('Configure a conexão com o Supabase em Ajustes antes de gerar problemas.');
  const { data: ficha, error: errFicha } = await supabaseClient
    .from('fichas').select('id')
    .eq('disciplina_id', disciplinaId).eq('topico', topico).maybeSingle();
  if(errFicha) throw errFicha;
  if(!ficha) throw new Error('Gere a ficha deste tópico antes de pedir um problema independente.');

  const { data: usados, error: errUsados } = await supabaseClient
    .from('problems').select('origem_chunk_id')
    .eq('ficha_id', ficha.id);
  if(errUsados) throw errUsados;
  const idsUsados = new Set((usados||[]).map(p=>p.origem_chunk_id).filter(Boolean));

  const chunks = await recuperarChunksComId(disciplinaId, topico, 8);
  const chunksNovos = chunks.filter(c=>!idsUsados.has(c.id));
  const pool = chunksNovos.length ? chunksNovos : chunks;
  const origem = pool[Math.floor(Math.random()*pool.length)];
  const fonte = `[1] ${origem.texto.slice(0,1500)}`;

  const d = DISC.find(x=>x.id===disciplinaId);
  async function gerarConteudoProblema(){
    CACHE.meta.chamadas = (CACHE.meta.chamadas||0)+1; salvarCache();
    const r = await fetch("https://api.anthropic.com/v1/messages", {
      method:"POST", headers: headersIA(),
      body: JSON.stringify({model:"claude-sonnet-5", max_tokens:800, messages:[{role:"user", content:
`Do trecho abaixo, extraia UM problema novo de aplicação prática sobre "${topico}" (${d.nome}, concurso fiscal) para o aluno resolver sozinho, sem ajuda. Baseie-se só no que está no trecho, sem inventar dado.
Responda APENAS com JSON: {"enunciado":"...","gabarito":"resposta final curta","correcao_detalhada":"explicação passo a passo"}

TRECHO:
${fonte}`}]})
    });
    const data = await r.json();
    const txt = data.content.map(c=>c.text||'').join('').replace(/```json|```/g,'').trim();
    const obj = JSON.parse(txt.slice(txt.indexOf('{'), txt.lastIndexOf('}')+1));
    if(!obj.enunciado || !obj.gabarito || !obj.correcao_detalhada) throw new Error('Resposta da IA incompleta.');
    return obj;
  }

  let conteudo = await gerarConteudoProblema();
  let revisao = await revisarConteudoIA('problema_independente', conteudo, fonte);
  let tentouRegenerar = false;
  if(!revisao.passou){
    tentouRegenerar = true;
    conteudo = await gerarConteudoProblema();
    revisao = await revisarConteudoIA('problema_independente', conteudo, fonte);
  }

  const { data: linha, error: errSalvar } = await supabaseClient.from('problems').insert({
    ficha_id: ficha.id,
    enunciado: conteudo.enunciado,
    gabarito: conteudo.gabarito,
    correcao_detalhada: conteudo.correcao_detalhada,
    origem_chunk_id: origem.id
  }).select().single();
  if(errSalvar) throw errSalvar;

  await gravarReviewLog({
    problem_id: linha.id, tipo_conteudo:'problema_independente',
    passou: revisao.passou, motivo_falha: revisao.motivo, tentativa_regeneracao: tentouRegenerar
  });
  linha.__avisoRevisao = !revisao.passou;
  return linha;
}
```
